Mathematics in Zombieland

Spreadsheet-Aligned Formula Guide
SUDZ state variables • kbamzr rate variables • exact iterative calculations

Purpose and source

This guide rewrites the mathematical model exactly as it is implemented in miz-model.xlsx (the same file as “1 year model mathmatics in zombieland v2.xlsx”). The workbook advances the population one numbered iteration at a time; it does not directly evaluate continuous-time derivative equations. Every population result is also prevented from becoming negative by Excel’s IF(…<0,0,…) wrapper.

Exact SUDZ update formulas

Define clamp(x) = max(0, x). Then the workbook calculates:

Susceptible: Sn+1 = clamp[Sn + h(bnSn − m0Sn − a0SnZn)]

Undead: Un+1 = clamp[Un + h(anSnZn − znUn) − rnUn]

Dead: Dn+1 = clamp[Dn + h(knSnZn + mnSn)]

Zombies: Zn+1 = clamp[Zn + znrnUn − hknSnZn]

Workbook-specific detail: the susceptible formula fixes a and m to baseline cells B13 and B14 (shown as a0 and m0), even after later columns change an or mn. The undead, dead, and zombie formulas use rates from the current iteration. This guide preserves that behavior for spreadsheet fidelity.

What each update adds and subtracts

  • Susceptible: begin with Sn; add scaled births hbnSn; subtract scaled ordinary deaths hm0Sn; subtract scaled infections ha0SnZn.
  • Undead: begin with Un; add scaled infections hanSnZn; subtract scaled zombification eligibility hznUn; then subtract the per-iteration converted share rnUn.
  • Dead: begin with Dn; add scaled zombies killed hknSnZn and scaled ordinary deaths hmnSn. This row is cumulative.
  • Zombies: begin with Zn; add undead who complete conversion znrnUn; subtract scaled zombies killed hknSnZn.

Excel cell form for one step (B → C)

These are simplified but cell-faithful versions of C4:C7:

C4 = MAX(0, B4 + $C$3 × (B12×B4 − $B$14×B4 − $B$13×B4×B7))

C5 = MAX(0, B5 + $C$3 × (B13×B4×B7 − B15×B5) − B16×B5)

C6 = MAX(0, B6 + $C$3 × (B11×B4×B7 + B14×B4))

C7 = MAX(0, B7 + B15×B5×B16 − $C$3×B11×B4×B7)

Interactions and cumulative interactions

  • Interactions at iteration n: In = hSnZn
  • Cumulative interactions: T1 = I1 and Tn = Tn−1 + In

Corrections to the short formulas in the task guide

  • “Change in Zombies = zU − kSZ” omits both h and r. The workbook update is Zn+1 = clamp[Zn + znrnUn − hknSnZn].
  • “Change in Undead = aSZ − zU” omits h, r, the prior U value, and the workbook’s placement of r outside h. Use the full U update above.
  • “Change in Dead = kSZ + mS” captures the two flows but omits h, the prior cumulative D value, and the zero clamp.
  • “Change in Susceptible = bS − mS − aSZ” captures the three flows but omits h, the prior S value, the clamp, and the workbook’s fixed baseline references for a and m.
  • The task guide states that the current birth rate is 0.03. The workbook’s No Action baseline is 0.003; 0.03 begins in Phase 4. Use the value in the relevant workbook column.

Reading the model correctly

  • Each new column uses the previous column’s S, U, D, and Z values and the previous column’s rate settings.
  • The IF wrapper turns any negative proposed population into zero; the workbook does not permit negative SUDZ values.
  • The factor h scales births, deaths, encounters, infection, and the zU subtraction in U, but it does not scale rU in U or zrU in Z.
  • The spreadsheet is not perfectly mass-conserving. Explain results as outputs of this workbook rather than assuming every person removed from one row appears identically in another.
