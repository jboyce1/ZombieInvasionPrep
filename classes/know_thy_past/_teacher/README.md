# Know Thy Past teacher resources

This directory is committed for instructor access but excluded from the generated GitHub Pages site.

- `plague-tag-worksheet.xlsx`: disease-model timing profiles used to run Class 1.
- `common-source-challenge-brief.docx`: instructor scenario and radio brief for Class 2.
- `common-source-challenge.xlsx`: five generated scenarios, hidden answer data, calculation sheet, and channels for Class 2.
- `epidemic-assignments.docx`: group disease assignments for Class 3.
- `triangulation-challenge.xlsx`: instructor challenge/control workbook for Class 4.

Do not link these files from student-facing pages. The repository itself may still expose committed files to anyone with repository access; the site exclusion only prevents normal GitHub Pages publication.
