# M3 Class 2 — Securing Supplies and Tracing the Story

**Module**: Know Thy Topos

**Class**: Class 2

**Focus**: securing a load and testing whether a narrative communicates a route accurately

**Skill**: Tie down supplies

**Activity**: Peer topo-narrative route trace

---

## Essential Question

**What makes a route description precise enough for someone else to trust and follow?**

---

## Objectives

* Build and inspect a tie-down system using the demonstrated knots.
* Secure a practice load so it resists movement without damaging the supplies.
* Trace a peer group's route using only the evidence supplied in its narrative.
* Compare the interpreted route with the authors' intended route.
* Give specific feedback about ambiguous or effective geographic language.

# Skill: Tie Down Supplies

### `0945–1025`

The purpose of a tie-down is to keep a load from shifting during movement. Use only the instructor-provided practice load and anchor points.

1. Inspect the rope, supplies, and anchor points before beginning.
2. Arrange the load so its weight is stable and fragile items are protected.
3. Attach the fixed end with the demonstrated releasable bowline.
4. Use a trucker's hitch to create controlled tension.
5. Secure the system with the demonstrated half hitches.
6. Check the load from several directions. It should resist shifting, while the rope should not crush or damage the supplies.
7. Receive an instructor inspection before moving or loading the system.
8. Release the system in a controlled way and coil the rope when finished.

Keep fingers away from tightening points. Do not wrap rope around a hand or body, suspend a person, secure a load overhead, or use the classroom system for vehicle transport.

# Peer Topo-Narrative Route Trace

### `1025–1105`

Your group will receive a survival narrative written by another group. Work from the narrative and an unmarked copy of the 1997 Pittsburgh West map.

## Your Task

1. Identify the stated starting location.
2. Trace the route in the order described.
3. Mark the terrain features that support each major decision.
4. Record the direction and estimated distance of each segment when the narrative provides enough evidence.
5. Mark the endpoint you believe the authors intended.
6. Identify one part of the narrative that was especially useful and one part that allowed more than one reasonable interpretation.

Do not ask the authors to explain the route while tracing it. Their written narrative is the evidence being tested.

# Compare, Feedback, and Revision

### `1105–1120`

Meet with the narrative's authors and compare your traced route with their intended route.

Discuss:

* Where did the routes agree?
* Which words or details made those portions clear?
* Where did the routes separate?
* Was the difference caused by a map-reading error, missing evidence, or ambiguous language?
* What is the smallest revision that would make the intended route clearer without simply giving away the answer?

Return the traced map and feedback to the authors. The authors then record the revision they would make.
